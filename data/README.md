# Data folder (local only)

Place your exported Phyphox CSV files here.

Recommended naming:
- `Raw Data Speed 1.csv`
- `Raw Data Speed 2.csv`

By default, this repo's `.gitignore` prevents committing raw CSV data.
That keeps the repository clean and avoids accidentally publishing personal sensor logs.

If you *want* to commit your data, remove the `data/*.csv` rule from `.gitignore`.
